# Project Principles: 昭和社員転生診断

最終更新日: 2026-05-08
管理者: ユーザー

## このツールは何のためのものか

令和のユーザーが昭和の会社に転生したら、どんな社員アバターになるかを判定するバラエティ系ネタ診断です。

正式タイトル:

- 転生したら昭和の社員だった件

診断名/共有用名称:

- 昭和社員転生診断

目指すこと:

- 飲み会やSNSで「これお前じゃん」と笑える診断にする。
- タイプ名は尖らせつつ、本文では強みや笑えるポイントに変換する。
- メイン16タイプに、サブ罪状、令和NGタグ、NG濃度でバリエーションを出す。

目指さないこと:

- 現代の能力、人格、職業適性を決めること。
- 現実の人事評価や採用判断に使える診断にすること。
- 現代の本人を直接攻撃すること。

## 優先する価値

1. SNSで共有したくなるネタ感
2. 「ちょっと刺さるけど笑える」バランス
3. 昭和転生アバターとしての安全な距離
4. 16タイプ構造を保った実装のシンプルさ

## Owner Style / Philosophy Profile

このプロジェクトでは、人間の「なんか違う」「装飾はいらない気がする」「20%でも十分すごい」といった判断を、AIの一般論より優先する。

大切にする判断軸:

- 人間がプロダクト判断を行い、AIは実装、検証、整理、レビューを支援する。
- 効果評価は過大に盛らず、実測できることと推定を分ける。
- 便利でも、プロダクトの世界観やユーザー体験を濁す装飾は削る。
- 公開URL、正リポジトリ、正本ドキュメントを固定し、AIが迷子にならない状態を重視する。

好む方向:

- 小さく直して、build/test/スクリーンショット/公開URLで確認する。
- AIの価値は「全部自動で作る」より、手戻りと確認漏れを減らすこととして評価する。
- 結果画面や共有画像は、ユーザーが見て理解しやすい一致感を優先する。

避けたい方向:

- AIやDevAideを魔法のように表現すること。
- 人間の違和感を、AIが論理だけで上書きすること。
- 旧投資家診断や別Vercelプロジェクトの文脈へ戻ること。
- DevAideを単なるプロンプト集、便利カード集、AIタスク管理、handoff要約ツールへ寄せること。

## 安全ライン

- 現代の本人を「パワハラ」「無能」「老害」などと直接断定しない。
- あくまで昭和に転生した架空アバターとして扱う。
- 結果文には必ず「令和では封印したいムーブ」「令和への帰還メモ」で救いを入れる。
- タイプ名は尖らせるが、本文では強みや昭和なら評価されたポイントに変換する。
- 現実の人事評価、適職診断、能力診断に見せない。

## 壊してはいけない前提

- メイン結果は16タイプ固定。
- 現行の4軸、12問、各軸3問構造を活かす。
- ユーザーにはタイプコードや軸名を前面に出しすぎない。
- `src/diagnosisData.ts` が診断データの正本。
- `src/diagnosisLogic.ts` がスコア計算と共有文の正本。
- `src/App.tsx` が画面本体。

## Not Doing / Rejected Ideas

| 種類 | 内容 | 理由 | 再検討条件 |
|---|---|---|---|
| 明確にやらない | 16タイプ以上に増やす | 診断構造、テスト、結果画像、共有導線が重くなり、ネタ診断としての見通しが悪くなる | 人間が新シリーズ化を判断した場合のみ |
| 明確にやらない | 現代の本人の人格/能力/適職を断定する | バラエティ診断の安全な距離を壊すため | 条件なし |
| 今はやらない | 複数AIの常時並行運用 | 公開済みの小規模アプリで、現時点はCodex単独の方が管理しやすい | 画像/文言/実装を複数担当へ分ける時 |
| 今はやらない | 追加の大型自動化 | 公開後の保守では、まず手動確認と小さな修正で十分 | 定期更新や監視が必要になった時 |
| 競合リスクで保留 | DevAideをプロンプト集/タスク管理/検索AIとして広げる | Skills、Plugins、Automations、既存AI機能と重なり、独自性が薄まる | 人間側参謀としての必要性が明確な場合のみ |

## Consistency Check

新しい提案、修正、レビュー、DevAide更新は以下と矛盾していないか確認する。

- 4軸、16タイプ、12問、タイプコード固定。
- 昭和転生アバターとしての安全な距離。
- 完成済み結果カード画像を画面プレビュー/保存物の正本にする方針。
- 本番URL `https://work-style-diagnosis.vercel.app/`。
- 正式作業場所 `/Volumes/My Passport for Mac/development/work-style-diagnosis`。
- Not Doing / Rejected Ideas。

矛盾する場合は、AIだけで解決せず人間判断へ戻す。
